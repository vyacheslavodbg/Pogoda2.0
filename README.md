# ATLAS — Earth Intelligence

Премиальный dark web-app для мониторинга условий в **Варне** и **Одессе**.

### Что внутри
- Погода: температура, ощущаемая температура, влажность, ветер, давление, видимость, UV и прогноз.
- Качество воздуха: EU AQI, PM2.5, PM10, O₃.
- Геомагнитная обстановка: Planetary K-index, максимум за последние значения и прогноз.
- Солнечная активность: solar wind и X-ray flux.
- Землетрясения: последние 30 дней в локальном географическом диапазоне, магнитуда и расстояние.
- Адаптивный интерфейс для iPhone и desktop.
- Никакого backend и API-ключей для базовой версии.

### Источники
- Open-Meteo Weather / Air Quality
- NOAA Space Weather Prediction Center
- USGS Earthquake Catalog

Open-Meteo требует атрибуцию для данных, поэтому источники указаны в интерфейсе и README. Для коммерческого использования проверьте условия соответствующих API.

### Запуск
Приложение статическое. Для GitHub Pages достаточно загрузить `index.html`, `styles.css`, `app.js` и `README.md` в репозиторий.

Локально можно открыть `index.html` через любой статический сервер, например:

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080`.
